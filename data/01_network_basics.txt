พื้นฐานระบบเครือข่ายคอมพิวเตอร์

ระบบเครือข่ายคอมพิวเตอร์ หรือ Computer Network คือการเชื่อมต่ออุปกรณ์ตั้งแต่สองเครื่องขึ้นไปเข้าด้วยกัน เพื่อให้สามารถสื่อสาร แลกเปลี่ยนข้อมูล และใช้ทรัพยากรร่วมกันได้ อุปกรณ์ที่อยู่ปลายทางของการสื่อสารเรียกว่า Host หรือ End Device ตัวอย่างเช่น เครื่องคอมพิวเตอร์ Notebook โทรศัพท์มือถือ Tablet Printer Server กล้องวงจรปิด และอุปกรณ์ IoT ส่วนอุปกรณ์ที่ช่วยให้ข้อมูลเดินทางระหว่างต้นทางและปลายทาง ได้แก่ Switch, Router, Access Point, Firewall และอุปกรณ์เครือข่ายอื่น ๆ

การสื่อสารในเครือข่ายจะไม่เกิดขึ้นแบบอิสระ แต่ต้องมีกฎหรือข้อกำหนดที่เรียกว่า Protocol เพื่อกำหนดรูปแบบ วิธีการส่งข้อมูล วิธีการรับข้อมูล การตรวจสอบความถูกต้อง และการจัดการกรณีที่ข้อมูลเกิดความผิดพลาด ตัวอย่าง Protocol ที่สำคัญ ได้แก่ Ethernet, ARP, IP, ICMP, TCP, UDP, DNS, DHCP, HTTP และ HTTPS แต่ละ Protocol มีหน้าที่แตกต่างกันและทำงานร่วมกันเป็นลำดับชั้นเพื่อให้การสื่อสารสำเร็จ

ข้อมูลที่ถูกส่งผ่านเครือข่ายจะถูกแบ่งออกเป็นหน่วยย่อยตามชั้นการทำงาน ตัวอย่างเช่น ในระดับ Application จะเป็นข้อมูลที่ผู้ใช้ต้องการส่ง เมื่อผ่าน Transport Layer จะถูกจัดการเป็น Segment หรือ Datagram จากนั้น Internet Layer จะเพิ่มข้อมูล IP Address และกลายเป็น Packet เมื่อเข้าสู่ Network Access Layer จะถูกบรรจุเป็น Frame และส่งผ่านสื่อจริง เช่น สาย Ethernet หรือสัญญาณ Wi-Fi การแบ่งข้อมูลเป็นหน่วยย่อยช่วยให้ระบบสามารถจัดการการส่งข้อมูล ตรวจสอบข้อผิดพลาด และส่งต่อข้อมูลได้อย่างมีประสิทธิภาพ

ประเภทของเครือข่ายสามารถแบ่งตามขนาดและพื้นที่ให้บริการได้หลายรูปแบบ LAN หรือ Local Area Network คือเครือข่ายในพื้นที่จำกัด เช่น บ้าน ห้องปฏิบัติการ อาคารสำนักงาน โรงเรียน หรือมหาวิทยาลัย LAN มักมีความเร็วสูงและดูแลโดยเจ้าของพื้นที่เอง ส่วน WLAN หรือ Wireless Local Area Network เป็น LAN ที่เชื่อมต่อผ่านเครือข่ายไร้สาย เช่น Wi-Fi

WAN หรือ Wide Area Network คือเครือข่ายที่เชื่อมต่อพื้นที่ที่อยู่ห่างกัน เช่น สำนักงานใหญ่กับสำนักงานสาขา หรือเครือข่ายระหว่างจังหวัดและประเทศ การเชื่อมต่อ WAN อาจอาศัยบริการของผู้ให้บริการเครือข่าย เช่น leased line, MPLS, VPN หรือ Internet ในภาพรวม Internet ถือเป็นเครือข่ายขนาดใหญ่มากที่เชื่อมต่อเครือข่ายย่อยจำนวนมากทั่วโลกเข้าด้วยกัน

อุปกรณ์สำคัญในเครือข่ายภายในคือ Switch ซึ่งทำหน้าที่เชื่อมต่ออุปกรณ์หลายเครื่องภายใน LAN Switch โดยทั่วไปทำงานใน Data Link Layer และเรียนรู้ MAC Address ของอุปกรณ์ที่เชื่อมต่ออยู่ในแต่ละพอร์ต เมื่อได้รับ Ethernet Frame Switch จะตรวจ Destination MAC Address แล้วส่ง Frame ไปยังพอร์ตที่เหมาะสม หากยังไม่ทราบว่า MAC Address ปลายทางอยู่ที่พอร์ตใด Switch อาจกระจาย Frame ไปหลายพอร์ตภายใน Broadcast Domain

Router เป็นอุปกรณ์ที่ใช้เชื่อมต่อเครือข่าย IP ที่แตกต่างกัน Router ทำงานหลักใน Network Layer และใช้ IP Address ในการตัดสินใจส่งต่อ Packet โดยพิจารณาจาก Routing Table หากปลายทางอยู่คนละ Network เครื่องต้นทางจะส่งข้อมูลไปยัง Default Gateway ซึ่งมักเป็น IP Address ของ Router Interface ที่อยู่ใน Subnet เดียวกับเครื่องนั้น จากนั้น Router จะตรวจ Routing Table และเลือกเส้นทางที่เหมาะสมเพื่อส่ง Packet ต่อไปยังเครือข่ายปลายทาง

Access Point หรือ AP เป็นอุปกรณ์ที่ช่วยให้อุปกรณ์ไร้สาย เช่น Notebook หรือ Smartphone สามารถเชื่อมต่อเข้าสู่ LAN ผ่าน Wi-Fi ได้ Access Point จะเชื่อมเครือข่ายไร้สายเข้ากับเครือข่ายแบบสาย และมักทำงานร่วมกับ Switch หรือ Router ในองค์กร

แบบจำลอง TCP/IP เป็นแนวคิดสำคัญในการอธิบายการสื่อสารเครือข่าย โดยทั่วไปแบ่งเป็น 4 ชั้น ได้แก่ Application, Transport, Internet และ Network Access

Application Layer เป็นชั้นที่เกี่ยวข้องกับบริการที่ผู้ใช้และโปรแกรมใช้งาน ตัวอย่าง Protocol เช่น HTTP และ HTTPS สำหรับเว็บไซต์ DNS สำหรับแปลงชื่อ Domain Name เป็น IP Address DHCP สำหรับแจกค่าการตั้งค่าเครือข่าย และ SSH สำหรับการเชื่อมต่อไปบริหารเครื่องระยะไกล

Transport Layer ทำหน้าที่ควบคุมการสื่อสารระหว่าง Application ของต้นทางและปลายทาง Protocol สำคัญคือ TCP และ UDP

TCP หรือ Transmission Control Protocol เป็น Protocol แบบ Connection-Oriented หมายถึงมีการสร้างการเชื่อมต่อก่อนส่งข้อมูล TCP เน้นความถูกต้องและความน่าเชื่อถือ มีการเรียงลำดับข้อมูล ตรวจสอบว่าข้อมูลมาถึงครบ และสามารถส่งข้อมูลซ้ำเมื่อเกิดการสูญหาย จึงเหมาะกับงานที่ต้องการความถูกต้อง เช่น เว็บไซต์ การโอนไฟล์ และการรับส่งข้อมูลสำคัญ

UDP หรือ User Datagram Protocol เป็น Protocol ที่ไม่มีขั้นตอนการสร้าง Connection แบบ TCP จึงมี Overhead ต่ำกว่าและทำงานรวดเร็วกว่า แต่ไม่มีการรับประกันว่าข้อมูลจะมาถึงครบหรือเรียงลำดับถูกต้อง UDP มักใช้ในงานที่ให้ความสำคัญกับความรวดเร็ว เช่น Streaming, Voice over IP, Online Game และบางส่วนของ DNS

Internet Layer ทำหน้าที่กำหนดที่อยู่เชิงตรรกะและหาเส้นทางของข้อมูล Protocol สำคัญคือ IP หรือ Internet Protocol ซึ่งใช้ IP Address เพื่อระบุต้นทางและปลายทางของ Packet นอกจากนี้ยังมี ICMP ที่ใช้สำหรับข้อความควบคุมและการตรวจสอบเครือข่าย เช่น คำสั่ง ping

Network Access Layer ทำหน้าที่เกี่ยวกับการส่งข้อมูลบนสื่อจริง เช่น Ethernet และ Wi-Fi รวมถึงการใช้ MAC Address และ Frame เพื่อส่งข้อมูลภายในเครือข่ายท้องถิ่น

MAC Address เป็นหมายเลขประจำ Network Interface ในระดับ Data Link โดยทั่วไปเขียนในรูปเลขฐานสิบหก เช่น 00:1A:2B:3C:4D:5E MAC Address ใช้สำหรับการสื่อสารภายใน LAN และช่วยให้ Switch ทราบว่า Frame ควรถูกส่งไปยังอุปกรณ์ใด

IP Address เป็นหมายเลขเชิงตรรกะที่ใช้ระบุตำแหน่งของอุปกรณ์ในเครือข่ายและใช้สำหรับการสื่อสารข้าม Network IP Address สามารถเปลี่ยนแปลงได้ตามการตั้งค่าของระบบ แตกต่างจาก MAC Address ที่ผูกกับ Network Interface มากกว่า

ARP หรือ Address Resolution Protocol ใช้สำหรับค้นหา MAC Address ที่สัมพันธ์กับ IPv4 Address ในเครือข่ายเดียวกัน ตัวอย่างเช่น หากเครื่อง A ต้องการส่ง Frame ไปยังเครื่อง B และทราบ IP Address ของ B แต่ยังไม่ทราบ MAC Address เครื่อง A จะส่ง ARP Request แบบ Broadcast เพื่อถามว่าอุปกรณ์ใดเป็นเจ้าของ IP นั้น เครื่อง B จะตอบกลับด้วย ARP Reply แบบ Unicast พร้อม MAC Address ของตน จากนั้นเครื่อง A จะบันทึกข้อมูลไว้ใน ARP Cache ชั่วคราว

Default Gateway คือ IP Address ของ Router Interface ที่อยู่ใน Subnet เดียวกับเครื่องผู้ใช้ หากเครื่องต้องการติดต่อปลายทางที่อยู่ใน Network อื่น จะส่ง Frame ไปยัง MAC Address ของ Default Gateway เพื่อให้ Router เป็นผู้ส่งต่อ Packet ไปยังเครือข่ายปลายทาง หากตั้ง Default Gateway ไม่ถูกต้อง เครื่องอาจยังสื่อสารกับอุปกรณ์ที่อยู่ใน Subnet เดียวกันได้ แต่ไม่สามารถเข้าถึง Network อื่นหรือ Internet ได้

DNS หรือ Domain Name System ช่วยแปลงชื่อที่มนุษย์อ่านง่าย เช่น example.com ให้เป็น IP Address ที่เครื่องคอมพิวเตอร์ใช้ในการสื่อสาร หาก DNS มีปัญหา ผู้ใช้อาจ ping IP Address ภายนอกได้ แต่ไม่สามารถเปิดเว็บไซต์ด้วยชื่อ Domain ได้

DHCP หรือ Dynamic Host Configuration Protocol ใช้สำหรับแจกค่าการตั้งค่าเครือข่ายให้ Client โดยอัตโนมัติ เช่น IP Address, Subnet Mask, Default Gateway และ DNS Server ช่วยลดการตั้งค่าด้วยตนเองและลดโอกาสเกิด IP Address ซ้ำ

HTTP หรือ Hypertext Transfer Protocol ใช้สำหรับรับส่งข้อมูลเว็บไซต์ ส่วน HTTPS คือ HTTP ที่มีการเข้ารหัสด้วย TLS ทำให้ข้อมูลระหว่าง Client และ Server ปลอดภัยมากขึ้น

การตรวจสอบปัญหาเครือข่ายควรทำอย่างเป็นขั้นตอน โดยเริ่มจากชั้นล่างขึ้นบน ขั้นแรกควรตรวจสอบสายเชื่อมต่อ สถานะ Link และไฟแสดงสถานะของ Network Interface จากนั้นตรวจค่า IP Address, Subnet Mask หรือ Prefix, Default Gateway และ DNS Server ว่าถูกต้องหรือไม่

คำสั่ง ping ใช้ทดสอบการเข้าถึงปลายทางและตรวจสอบการทำงานของ IP Connectivity โดยอาศัย ICMP Echo Request และ Echo Reply หาก ping Default Gateway ไม่ได้ ปัญหาอาจอยู่ที่ LAN, IP Configuration, VLAN หรืออุปกรณ์เครือข่าย หาก ping Gateway ได้แต่ ping ปลายทางภายนอกไม่ได้ ปัญหาอาจเกี่ยวกับ Routing, NAT หรือ Firewall

คำสั่ง tracert บน Windows และ traceroute บน Linux ใช้ตรวจสอบเส้นทางที่ Packet เดินทางผ่าน Router แต่ละจุดก่อนถึงปลายทาง ช่วยระบุได้ว่าการสื่อสารหยุดอยู่บริเวณใด

คำสั่ง nslookup และ dig ใช้ตรวจสอบการทำงานของ DNS หากสามารถ ping IP Address เช่น 8.8.8.8 ได้ แต่ไม่สามารถเข้าถึงเว็บไซต์ด้วยชื่อ Domain ได้ ควรตรวจ DNS Server และการ Resolve ชื่อ

Bandwidth คือความจุสูงสุดของช่องทางสื่อสารในช่วงเวลาหนึ่ง ตัวอย่างเช่น Link 1 Gbps สามารถส่งข้อมูลได้ตามขีดจำกัดทางทฤษฎีสูงสุดประมาณ 1 Gigabit ต่อวินาที

Throughput คือปริมาณข้อมูลที่ส่งได้จริง ซึ่งมักต่ำกว่า Bandwidth เนื่องจากมี Overhead, Traffic อื่นในระบบ, ความหน่วง และข้อจำกัดของอุปกรณ์

Latency คือเวลาหน่วงที่ข้อมูลใช้เดินทางจากต้นทางถึงปลายทาง ค่า Latency สูงอาจส่งผลต่อ Application แบบ Real-time เช่น Video Call หรือ Online Game

Packet Loss คือสัดส่วนของ Packet ที่สูญหายระหว่างการส่ง หากมี Packet Loss สูง TCP อาจต้องส่งข้อมูลซ้ำ ส่งผลให้ Throughput ลดลงและประสบการณ์ใช้งานแย่ลง

Duplex ระบุทิศทางการสื่อสาร Half Duplex สามารถส่งหรือรับข้อมูลได้ทีละทิศทาง ส่วน Full Duplex สามารถส่งและรับข้อมูลพร้อมกันได้ Ethernet สมัยใหม่ทั่วไปใช้ Full Duplex

Broadcast เป็นการส่งข้อมูลจากอุปกรณ์หนึ่งไปยังทุกอุปกรณ์ใน Broadcast Domain ตัวอย่างเช่น ARP Request ส่วน Unicast เป็นการส่งจากต้นทางหนึ่งไปยังปลายทางหนึ่ง และ Multicast เป็นการส่งไปยังกลุ่มอุปกรณ์ที่สนใจข้อมูลนั้น

Broadcast Domain คือขอบเขตที่ Broadcast Frame สามารถแพร่กระจายได้ Switch Layer 2 โดยทั่วไปไม่ตัด Broadcast Domain แต่ Router จะไม่ส่งต่อ Layer 2 Broadcast ข้าม Network ทำให้ Router ใช้แยก Broadcast Domain ได้

Collision Domain ใน Ethernet แบบเก่าเป็นพื้นที่ที่อาจเกิดการชนกันของ Frame ปัจจุบันเมื่อใช้ Switch และ Full Duplex การชนกันแทบไม่เกิดขึ้นในแต่ละพอร์ต ทำให้ประสิทธิภาพดีขึ้นกว่า Hub

Topology คือรูปแบบการเชื่อมต่ออุปกรณ์ในเครือข่าย ตัวอย่างที่พบได้บ่อยคือ Star Topology ซึ่งให้อุปกรณ์ปลายทางเชื่อมเข้าหา Switch เป็นศูนย์กลาง ข้อดีคือดูแลและแก้ปัญหาง่าย หากสายของเครื่องหนึ่งเสียจะไม่กระทบเครื่องอื่นโดยตรง

เครือข่ายที่ดีควรออกแบบให้มีประสิทธิภาพ ความปลอดภัย ความพร้อมใช้งาน และรองรับการขยายในอนาคต ควรวางแผน IP Address, VLAN, Routing, Gateway, DHCP, DNS และ Firewall ให้สอดคล้องกัน รวมถึงมีเอกสาร Network Diagram และบันทึกค่าการตั้งค่าเพื่อให้ง่ายต่อการดูแลและแก้ปัญหา

2. ตรวจสอบว่า Network Interface เปิดใช้งานอยู่
3. ตรวจสอบ IP Address และ Subnet Mask
4. ตรวจสอบ Default Gateway
5. ตรวจสอบ DNS Server
6. ping IP Address ของตนเอง
7. ping Default Gateway
8. ping IP Address ภายนอก

เครื่อง Client ใช้ IP 192.168.10.20/24 และ Gateway 192.168.10.1 หากสามารถ ping 192.168.10.1 ได้ แต่ ping 8.8.8.8 ไม่ได้ ควรตรวจสอบ Router, Default Route, NAT หรือการเชื่อมต่อ Internet

สรุปคำศัพท์สำคัญ

Host หรือ End Device
อุปกรณ์ปลายทางที่ส่งหรือรับข้อมูล เช่น Computer, Server และ Smartphone

Switch
อุปกรณ์เชื่อมต่อภายใน LAN และใช้ MAC Address ในการส่ง Frame

Router
อุปกรณ์เชื่อมต่อ Network ที่แตกต่างกันและใช้ Routing Table ในการส่ง Packet

Access Point
อุปกรณ์เชื่อม Client แบบไร้สายเข้าสู่ LAN

Protocol
กฎและรูปแบบที่อุปกรณ์ใช้ในการสื่อสารกัน

LAN
เครือข่ายในพื้นที่จำกัด เช่น อาคารหรือห้องปฏิบัติการ

WAN
เครือข่ายที่ครอบคลุมพื้นที่กว้างและเชื่อมหลาย LAN เข้าด้วยกัน

MAC Address
หมายเลขที่ใช้ระบุ Network Interface ในระดับ Data Link

IP Address
ที่อยู่เชิงตรรกะสำหรับระบุอุปกรณ์และเครือข่าย

Default Gateway
Router ที่เครื่องใช้สำหรับส่งข้อมูลไปยัง Network อื่น

ARP
Protocol สำหรับค้นหา MAC Address จาก IPv4 Address ภายใน LAN

DNS
ระบบแปลง Domain Name เป็น IP Address

DHCP
Protocol สำหรับแจก Network Configuration ให้ Client โดยอัตโนมัติ

TCP
Transport Protocol ที่เน้นความถูกต้องและความน่าเชื่อถือ

UDP
Transport Protocol ที่ลดขั้นตอนและเน้นความรวดเร็ว

ICMP
Protocol สำหรับข้อความควบคุมและการตรวจสอบ เช่น ping

Bandwidth
ความจุสูงสุดของ Link

Throughput
ปริมาณข้อมูลที่ส่งได้จริง

Latency
ระยะเวลาหน่วงของการสื่อสาร

Packet Loss
Packet ที่สูญหายระหว่างทาง

Routing Table
ตารางข้อมูลเส้นทางที่ Router หรือ Host ใช้ในการเลือกทางส่ง Packet
